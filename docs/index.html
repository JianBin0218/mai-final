一動機與架構Motivation

同一個模型寫 latent，
也讀 latent。

Qwen2-Audio 跑兩次。第一次讀音訊、題目和選項，在 K 個位置寫出 latent；第二次讀題目、選項和 latent 作答。三個條件只差在第二次能不能直接聽到原音訊。CoAT 等音訊 latent reasoning 方法屬於 Soft：回答時仍讀得到音訊。

固定不動

同一個寫入架構

Qwen2-Audio-7B 跑兩次，共用一組 LoRA（q、v 投影，rank 8）。寫入端讀音訊、題目和選項，寫出 K = 4 個 latent；回答端讀題目、選項和 latent，以選項字母 logit 作答。

變因一

回答端的音訊

Soft 保留原音訊；Hard 拿掉；Mid 訓練時以 0.5 機率遮掉，評估時兩種都報。三組各自訓練。

變因二

只改 latent

固定訓練好的模型和其他所有輸入，把 latent 換成別題的、評估集平均、全零，或加噪，看答案改變多少。

對照

分開 latent 與微調

純 LoRA（沒有 latent）、K = 0（只有邊界 token）、重建損失（逼 latent 記住音訊），以及寫入端不看題。

五常見疑問Notes

幾個容易混淆的概念。

i.Qwen2-Audio 怎麼讀聲音？

Qwen2-Audio 先用音訊編碼器把錄音轉成一串向量，投影到語言模型的 embedding 空間，再插進題目文字之間。之後語言模型就像處理一般 token 一樣，用同一套 Transformer 層一起處理聲音向量和文字。

B4 的寫入端和回答端是同一個模型，用 LoRA 微調。早期 A、B、C 的實驗則讓語言模型完全凍結，只訓練外部壓縮器或轉接層。

ii.這裡的 latent 是什麼？

在 B4 裡，latent 是 Qwen 第一次跑時，K 個可學習位置在最後一層的 hidden state。它們是 4096 維的連續向量，不對應任何文字。第二次跑時放在 start 與 end token 之間，讓回答端讀。

早期 A、B、C 的 latent 是 LLM 外部的小壓縮器輸出，放在原本音訊 token 的位置。那是「音訊 token 壓縮」；B4 才是 LLM 自己寫的 latent。

iii.「沒有用 latent」是怎麼量的？

固定訓練好的模型、音訊、題目和選項，只把 latent 換成別題的、平均、全零或加噪。答案幾乎不變，就表示這個模型在這個條件下不依賴 latent。

也看分數：Soft 和純 LoRA、K = 0 一樣，表示微調的提升不是 latent 帶來的。這裡量的是答案有沒有用到 latent，不是 latent 裡有沒有資訊。

iv.latent 有聲音資訊，為什麼答案還是不用？

加重建損失後，latent 能重建音訊 token 的分段平均，代表它記住一部分聲音。但拿掉音訊再介入，答案也只改變 0.7–1.2%，分數接近純文字基準（44.4%；原模型純文字 41.9%）。

一個可能的解釋是：訓練時回答端一直聽得到原音訊，沒有壓力去學讀 latent。影像研究把這種現象稱為 latent bypass，B4 Soft 是它在音訊端的對應。

v.Hard 依賴 latent，代表 latent 在推理嗎？

還不能這樣說。寫入端讀得到題目和選項，可能先選好答案，再把答案寫進 latent。B3 的 K = 1 就達到完整音訊參考值；兩端選項順序不一致時，Hard 只答對 7–11%。兩者都符合這個解釋。

要分辨「傳答案」和「傳聲音證據」，需要能訓練的寫入端不看題版本、同題相反證據的配對交換，以及兩端獨立換選項順序。這是後續工作。

vi.為什麼用選項字母的 logit，而且每題評兩次？

AVQA 與 MMAU 是選擇題。直接比較每個選項字母的第一個 token 分數，評分規則固定，不需要生成文字。

模型可能偏好某個字母（MMAU 正解原本落在 A 的比例是 39.5%），所以每題以原順序與反轉順序各評一次，寫入端和回答端用同一個排列，再平均。

vii.開發與確認資料怎麼分？

AVQA-R1-6K 的訓練檔切成訓練 3,991 題、開發 500 題（seed 17）。MMAU test-mini 1,000 題作開發評估。MMAR 保留到確認方案固定後才評。

A 線的官方 Clotho-AQA test（514 題）是另一套事前固定的評估，屬於外部壓縮器的容量基準。
